## 📁 Aprendizados com esse projeto:
___

<ul>
    <li>Analisar o código de uma página HTML para entender sua estrutura e planejar o código de sua funcionalidade;</li>
    <li>Declarar variáveis no JavaScript para armazenar elementos recuperados da página;</li>
    <li>Recuperar elementos da página com JavaScript, com o uso da função document.getElementById();</li>
    <li>Recuperar valores digitados em campos de um formulário na página, via propriedade value;</li>
    <li>Utilizar o recurso de Template String, do JavaScript, para concatenar valores de variáveis em String.</li>
    <li>Utilizar a função parseInt, no JavaScript, para converter um valor do tipo String para um número inteiro;</li>
    <li>Fazer uma estrutura de repetição utilizando for para gerar números aleatórios no sorteador;</li>
    <li>Declarar uma variável do tipo array para representar uma lista;</li>
    <li>Adicionar um elemento a um array com a função push;</li>
    <li>Utilizar um código já desenvolvido por terceiros para realizar o sorteio de um número aleatório dentro de um intervalo.</li>
    <li>Declarar um bloco condicional if/else para implementar a funcionalidade de alterar o status do botão Reiniciar.</li>
    <li>Acessar a lista de classes que um elemento da página possui, via propriedade classList;</li>
    <li>Verificar se um elemento da página possui uma determinada classe CSS, via função classList.contains();</li>
    <li>Remover uma classe CSS de um elemento da página, via função classList.remove();</li>
    <li>Adicionar uma classe CSS a um elemento da página, via função classList.add();</li>
    <li>Modificar o código HTML de um elemento na página, via propriedade innerHTML.</li>
    <li>Demonstração</li>
</ul>
